# Financial ML 10 — Capstone: From Idea to Paper Trading

One idea taken through the whole professional pipeline. A pre-registered hypothesis about market regimes, a hidden Markov model written from scratch (forward filter, Baum–Welch, Viterbi), the look-ahead trap that makes regime models look miraculous, a walk-forward backtest with costs, honest tuning with a deflated Sharpe ratio, a single untouched hold-out test, an automatically generated research report, and a paper-trading loop that is reconciled against the backtest.

**Time:** About 5 hours with the exercises. **Before this:** The whole course, especially Chapters 1–5 and 9.

| File | What it is |
|---|---|
| `index.html` | The guide: theory and maths from scratch, all the code with its real outputs, all the figures. |
| `capstone.ipynb` | The complete notebook; it reproduces every number and figure in the guide. |
| `animations/regime_lab.html` | Interactive playground: Regime Lab. |
| `research_plan.json` | The pre-registered research plan, written by the notebook before any test. |
| `report.md` | The research report, generated by the notebook with every number from the computations. |
| `paper_trader/paper_trade.py` | The paper-trading loop (replay or live; idempotent, writes a ledger). |
| `paper_trader/config.json` | The paper trader's settings, frozen from the research. |
| `datasets/capstone_daily.csv` | Cached data (495 kB), so everything runs offline. |

## What you will do

1. Look at the big picture: write the plan before touching the data
2. Get the data
3. Explore the data: does the market have moods?
4. Hidden Markov models, from scratch
5. The look-ahead trap: filtered versus smoothed
6. Select and train: the walk-forward backtest
7. Fine-tune the model, honestly
8. The hold-out test, once
9. Present your solution: an automatically generated research report
10. Summary
11. Development period 2007–2020
12. Hold-out 2021–2026 (run once)
13. Risks and limitations
14. Launch, monitor and maintain: a paper-trading loop
15. Where to go from here

```bash
python3 -m pip install -U jupyter matplotlib numpy pandas scipy
jupyter notebook capstone.ipynb
```

Or open `index.html` in a browser to read the guide with every output already computed.
