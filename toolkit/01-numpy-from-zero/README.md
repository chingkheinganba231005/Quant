# Toolkit 1 — NumPy from Zero

The one library underneath every other: arrays, vectorised maths, broadcasting, linear algebra and random numbers, from the first array to the tricks quants use every day.

**Time:** About 3 hours with the exercises. **Before this:** Basic Python (lists, loops, functions).

| File | What it is |
|---|---|
| `index.html` | The guide: theory and maths from scratch, all the code with its real outputs, all the figures. |
| `numpy_from_zero.ipynb` | The complete notebook; it reproduces every number and figure in the guide. |
| `animations/numpy_playground.html` | Interactive playground: NumPy Playground. |

## What you will do

1. Setup
2. Why NumPy? A speed test
3. Creating arrays
4. dtypes: what is inside each box
5. Indexing and slicing
6. Vectorised arithmetic and universal functions
7. Aggregations and the meaning of `axis`
8. Broadcasting: how arrays of different shapes combine
9. Reshaping, combining, sorting
10. Linear algebra for portfolios
11. Random numbers and Monte Carlo
12. Performance tricks quants use
13. Saving and loading
14. The mistakes that cost quants money

## Run it

```bash
python3 -m pip install -U jupyter matplotlib numpy
jupyter notebook numpy_from_zero.ipynb
```

Or open `index.html` in a browser to read the guide with every output already computed.
